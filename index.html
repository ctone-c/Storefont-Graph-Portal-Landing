Storefront Graph Portal

Storefront Graph (formerly Federated Graph) is Volvo Cars’ GraphQL API data source for building great customer and retailer experiences. It provides a single entry point to discover data, explore types and queries, and run live examples.

Products (including cars) and Product Offers are represented in the commercial context, as seen on volvocars.com, including prices and taxes, technical data, rendered images, and much more.

Quick Start

  1. Build your query in the Explorer

    Open Explorer

  2. Register your client and copy the required headers

    federated-graph-client-name: my-client
federated-graph-client-key: <my client key>
    Go to Client Registry

  3. Send the query to the Storefront Graph endpoint

    Endpoint: https://graph.volvocars.com/graphql 

    const res = await fetch("https://graph.volvocars.com/graphql", {
  method: "POST",
  headers: {
    "content-type": "application/json",
    "federated-graph-client-name": "<YOUR CLIENT NAME>",
    "federated-graph-client-key":  "<YOUR CLIENT KEY>"
  },
  body: JSON.stringify({ query: "<YOUR QUERY AS TEXT>" })
});
if (!res.ok) { /* handle errors */ }
const data = await res.json();
    curl -X POST https://graph.volvocars.com/graphql \
  -H "content-type: application/json" \
  -H "federated-graph-client-name: <YOUR CLIENT NAME>" \
  -H "federated-graph-client-key: <YOUR CLIENT KEY>" \
  -d '{"query":"<YOUR QUERY AS TEXT>"}'
    HttpClient client = HttpClient.newHttpClient();
HttpRequest request = HttpRequest.newBuilder()
    .uri(URI.create("https://graph.volvocars.com/graphql"))
    .header("content-type", "application/json")
    .header("federated-graph-client-name", "<YOUR CLIENT NAME>")
    .header("federated-graph-client-key",  "<YOUR CLIENT KEY>")
    .POST(HttpRequest.BodyPublishers.ofString(
        "{\"query\":\"<YOUR QUERY AS TEXT>\"}"
    ))
    .build();
HttpResponse<String> response =
    client.send(request, HttpResponse.BodyHandlers.ofString());

Need help?

  1. Reproduce the issue with a minimal query in the Explorer
  2. Copy the link using the paper aeroplane icon ✈️
  3. Submit an issue via Slack, Teams or email

Your request will be routed to the right team – either the domain team that owns the data or the Federated Graph team for platform issues.

Data & domains

The Storefront Graph uses Federated GraphQL architecture — one unified API, with implementation and operational responsibility split across domain teams. You query one endpoint; each domain team owns their schema fields and data.

  • Products & Offers

    List and search product offers, including Cars

  • Configuration

    Configure products

  • Enrichment

    Translated text, environmental & technical data, rendered images, and more

  • Cart

    View prices and taxes

  • Volvo ID

    Account info

  • Fulfilment

    Lead times and fleet
